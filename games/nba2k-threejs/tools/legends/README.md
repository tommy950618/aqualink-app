# Legends body pipeline

Offline tools that turn the CC0 MakeHuman base mesh into realistic, rigged, per-player bodies for the
game. Nothing here runs in the browser except `loader-prototype.js`; the game ships only the baked files.

## Licence

The MakeHuman hm08 base mesh, the MPFB2 targets (macro and detail), the `game_engine` rig and its weights are
released under **CC0 1.0** (see the header of `base.obj` and
<https://raw.githubusercontent.com/makehumancommunity/mpfb2/master/LICENSE.md>, which states
that MPFB's data assets are CC0). MPFB's Python code is GPL: it was only read to understand the data formats and
the macro weighting maths; no code was copied. The scripts in this folder are part of this repository (MIT).
Hair, beards, skin, eyes and clothes are generated by us (shells + procedural textures); no third-party
texture or hair asset is used.

## Requirements

- Node 22 (built-ins only: `fs`, `path`, `zlib`, global `fetch`).
- Optional: `npm install` in this folder installs `meshoptimizer` (MIT) into `node_modules/` (gitignored).
  Without it the bake still works, but produces no LODs and does not decimate the shells.

## Fetch

```sh
node tools/legends/fetch.mjs                          # core: base.obj, rig/weights, target.json, macro.json, vertex groups
node tools/legends/fetch.mjs tools/legends/configs/poc.json   # + every target that config needs
```

Files come from `https://raw.githubusercontent.com/makehumancommunity/mpfb2/master/src/mpfb/data/` and are
cached under `tools/legends/.cache/` (gitignored, keeps the upstream relative paths). Downloads are retried
with backoff, are idempotent (an existing file is reused, 404s are remembered), and are treated as data only:
parsed as OBJ text, JSON or gzip'd target text, never executed. `bake.mjs` fetches missing targets on demand,
so running `fetch.mjs` first is optional.

## Bake

```sh
node tools/legends/bake.mjs tools/legends/configs/poc.json [--out <dir>] [--name <basename>]
```

Writes `<name>.json`, `<name>.shared.bin` and `<name>.<id>.bin` per player (format: `FORMAT.md`). The bake
log reports the rig self-check (the rig's stored `default_position`s are reproduced to 0.00 mm on the default
MakeHuman, which validates axes, units and the macro maths), skin statistics, shell sizes, LOD errors and each
player's measured height.

### Config

```jsonc
{
  "name": "poc",                                   // output basename
  "output": "../../../test/scratch/legends-poc/assets",   // relative to the config file
  "lods": [ { "ratio": 0.5, "lockHead": true },    // extra body index buffers (needs meshoptimizer)
            { "ratio": 0.25, "lockHead": true },   // lockHead keeps the face (front of the head) at full detail
            { "ratio": 0.12 } ],
  "keepMouth": false,                              // true keeps teeth + tongue as a 'mouth' submesh
  "shells": "default",                             // or an array of shell defs (see lib/shells.mjs DEFAULT_SHELLS)
  "players": [ {
    "id": "athlete",                               // [a-z0-9_-]
    "label": "free text",
    "height": 1.88,                                // barefoot body height in metres (max y of the mesh)
    "macro": {
      "gender": 1,           // 0 female .. 1 male
      "ageYears": 28,        // or "age" slider: 0.1875 = 11 y, 0.5 = 25 y, 1 = 90 y
      "muscle": 0.85,        // 0 .. 1 (0.5 average)
      "weight": 0.55,        // 0 .. 1 (0.5 average)
      "height": "auto",      // 0 .. 1, or "auto": slider solved so the raw MakeHuman height == "height"
      "proportions": 1,      // 0.5 neutral .. 1 ideal (athletic) proportions
      "race": { "african": 0.9, "asian": 0, "caucasian": 0.1 }   // normalised to sum 1
    },
    "targets": {             // detail modifiers "<group>/<modifier>": value in [-1, 1]
      "nose/nose-flaring-decr-incr": 0.5,        // + uses ...-incr, - uses ...-decr with |value|
      "head/head-square": 0.4,                   // one-sided modifiers take 0 .. 1
      "arms/upperarm-fat-decr-incr": { "l": 0.2, "r": 0.3 },   // l/r modifiers: number = both sides
      "nose/nose-hump-incr": 0.3                 // a raw target file name also works
    },
    "appearance": { }        // passed through to the header untouched (skin colour, hair, beard, accessories)
  } ]
}
```

Modifier names: every `categories[].name` in `.cache/targets/target.json`, grouped by `arms asym breast
buttocks cheek chin ears eyebrows eyes feet forehead genitals hands head hip legs mouth neck nose pelvis
stomach torso` (the full list is in the phase report and printed by
`node -e "const t=require('./tools/legends/.cache/targets/target.json');for(const g in t)console.log(g,t[g].categories.map(c=>c.name).join(' '))"`).

### The six legends (`legends.config.json`)

`legends.config.json` bakes `kobe`, `jordan`, `lebron`, `giannis`, `yao`, `kyrie` (barefoot heights 1.96, 1.96,
2.03, 2.09, 2.27, 1.87 m) from the likeness profiles. Its `notes` array lists every deviation from the profiles.
Extra per-player keys (all passed through to the baked header):

- `meta`: names (`nameEn`, `nameZh`), era, number, `stats` (listed height/weight/wingspan/reach) and
  `calibration` (the anthropometric targets solved by `calibrate.mjs`).
- `expressions`: named runtime blends in the same `"<group>/<modifier>": value` syntax (e.g. Kobe's `jawJut`).
  `bake.mjs` validates their names; baking them as morph deltas is a later step.
- `appearance` (consumed by the game, not by the bake): `skin`, `skinRoughness`, `lips`, `palms`, `iris`;
  `hair {shell|null, style: bald|buzz|buzz-receded|short-coils-fade|short-coils-taper|crew-cut-straight, lengthMm,
  color, coverage (texture opacity), hairline {aboveBrowCm, templeRecessionCm, ...}, extraOffsetMm}`;
  `eyebrows {shell, color, density, shape}`; `beard null | {shell, style: moustache-goatee|short-full|full,
  color, lengthMm, density {...}}`. The shared `beard` shell is a full beard, so goatee/short styles need a
  per-style alpha mask over it (or extra shells). `accessories [{type: sleeve|fingerTape|headband|wristband|
  tattoo|mouthguard, shell?, side?, color*, default}]`; `kit {number, default, home|away|alt {base, number,
  outline, trim}}`; `socks {shell, length, colorHome, colorAway}`; `shoes {cut, home[], away[]}`.

```sh
node tools/legends/bake.mjs tools/legends/legends.config.json        # -> test/scratch/legends-poc/assets/legends.*
node tools/legends/measure.mjs test/scratch/legends-poc/assets/legends.json
node test/scratch/legends-poc/shoot-legends.cjs lineup "lineup:yaw=1.5708" heads "heads:groom=1"
```

### Measure and calibrate

`measure.mjs <header.json> [--json]` reads only the baked files and reports, per player: height, head height and
"heads tall", the crown-to-eye : eye-to-chin ratio (`craniumFace`, about 1.0 for an adult face), shoulder-joint
breadth, chest/waist/hip breadth and depth, neck/thigh/calf breadth, wingspan and overhead reach (CPU skinning
with the arms straightened, no shoulder shrug: about 25 cm under a combine standing reach), hand and foot
length, leg ratio and a mass estimate (closed mesh volume x 1.12, which matches the listed weights of the
macro-only bodies).

`calibrate.mjs <config> [--iters n] [--write]` keeps every likeness modifier and solves a few knobs per player
against `meta.calibration` (`craniumFace`, `headH`, `shoulderJoints`, `handLen`, `footLen`, `massKg`,
`wingspan`), re-baking and re-measuring each iteration (about 2 s per iteration for six players). Knobs:
`forehead/forehead-scale-vert-decr-incr`, `head/head-scale-vert-decr-incr`, `torso/measure-shoulder-dist-decr-incr`,
`hands/hand-scale-decr-incr`, `feet/foot-scale-decr-incr`, both `arms/measure-*arm-length-decr-incr`, and
`macro.weight`. Run it again after editing likeness targets: leg/torso length targets change everything else,
because `height: "auto"` re-solves the height. Measured gains per +1 at fixed height: head-scale-vert +3.6 cm head
(both halves), forehead-scale-vert +3.6 cm crown only, forehead-nubian +3.3 cm crown, head-oval +1 cm crown,
chin-height +1.1 cm face, upper/lower arm length +14/+13 cm span, hand-scale +12 cm span, shoulder-dist +5 cm,
torso-scale-horiz +6.8 cm shoulders; macro muscle *reduces* volume at fixed height, macro weight adds about 40 kg/unit.

### Macro weighting (lib/targets.mjs)

Slider values are split into components with `macro.json` "parts": for each part with
`lowest < v < highest`, `t = (v - lowest)/(highest - lowest)`, `low` gets `1 - t`, `high` gets `t`. Race weights
are normalised. Applied targets (weight = product of component weights, kept when > 0.01):
`macrodetails/<race>-<gender>-<age>` (x race weight), `macrodetails/universal-<g>-<a>-<muscle>-<weight>`,
`macrodetails/height/<g>-<a>-<m>-<w>-<minheight|maxheight>`,
`macrodetails/proportions/<g>-<a>-<m>-<w>-<uncommonproportions|idealproportions>`. Detail targets are added after
the macro targets with their weight. Then the body is uniformly scaled to `height`.

## Runtime

`loader-prototype.js` (ES module, imports `../../vendor/three.module.js`):

```js
const lib = await loadLegends('assets/legends.json');
const p = await lib.createPlayer('athlete', {
  lod: 1,                                               // 0 = full body
  materials: { skin: skinMat, eye: eyeMat },            // per submesh material
  shells: { jersey: m1, shorts: m2, socks: m3, hair: m4, beard: m5, headband: m6 },   // worn shells
  shellFade: { hair: 0.008, beard: 0.01 },              // RGBA vertex alpha ramp at shell edges (use vertexColors + alphaTest)
  hideCovered: true,                                    // drop body triangles hidden under worn cloth (default)
});
scene.add(p.object);                  // THREE.Group: move/rotate this
p.bones.upperarm_r.rotation.z = -2.3; // bones by name, identity rest rotations
p.setLod(2); p.resetPose(); p.boneAxis('lowerarm_r'); p.landmark('l-eye');
```

Body + shells are `THREE.SkinnedMesh`es sharing one `THREE.Skeleton` per player; LODs and shells share GPU
buffers across players where possible (UV, index, skin attributes).
