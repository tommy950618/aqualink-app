# Legends bake pipeline (format v2)

Offline tools that turn the CC0 MakeHuman base mesh into the six rigged, groomed, expressive legends of
传奇对决 3v3 / LEGENDS 3v3 (SPEC-v2 §3, §8). The game ships only the baked files in `assets/legends/`; nothing in
this folder runs in the browser.

## Commands (run from `games/nba2k-threejs/`)

```bash
cd tools/legends && npm install                          # optional: meshoptimizer 0.22.0 (LOD indices, shell LOD1); once
node fetch.mjs legends.config.json                       # MPFB2 data pinned to mpfbRef, cached in .cache/, verified by assets.lock.json
node calibrate.mjs legends.config.json --write           # only after head/face/length modifier edits
node bake.mjs legends.config.json                        # → ../../assets/legends/ (header v2, 7 bins, 15 PNGs)
node measure.mjs ../../assets/legends/legends.json --likeness   # SPEC-v2 §10.2 bands and orderings
cd ../.. && node test/unit-legends-bake.mjs              # pipeline + asset checks, re-bake determinism when .cache exists
```

`package.json` scripts: `fetch:legends`, `verify:cache`, `bake:legends`, `calibrate:legends`, `measure:legends`,
`likeness` (bake + measure --likeness + `test/likeness/shoot.cjs`).

Requirements: Node 22 (built-ins only). `bake.mjs` exits 1 without meshoptimizer unless `--no-lod` is passed,
which writes `"devOnly": true` into the header (refused by the runtime outside `?debug=1`).

## Pinned inputs (`fetch.mjs`, `assets.lock.json`)

Every download comes from `https://raw.githubusercontent.com/makehumancommunity/mpfb2/<mpfbRef>/src/mpfb/data/…`
with `mpfbRef = d0a32e57a7f915cb2f2b95410e2117648c7bbb7e` (mpfb2 `master` on 2026-10-10). The committed
`assets.lock.json` records the ref, the fetch date and the byte size + SHA-256 of every cached file (297 files:
base mesh, rigs, weights, indexes and every target the configs need; upstream 404s are recorded as `missing`).
`fetch.mjs` and `bake.mjs` verify each cached file against it and stop on any mismatch; `node fetch.mjs --verify`
re-hashes the whole cache. The cache fetched from `master` before pinning was byte-identical to the pinned commit.
Downloaded files are data only: parsed as OBJ text, JSON or gzip'd target text, never executed.

## What the bake does (`bake.mjs`)

1. **Rig check**: rebuilds the default MakeHuman and compares every joint with the rig's stored
   `default_position` (log: `rig check … = 0.00 mm`).
2. **Topology**: body (hm08 skin) + teeth/tongue (`keepMouth`) + eyelash cards (lashes shell only) + two generated
   24 × 16 UV-sphere eyeballs (12 × 8 low index range); lip-seam vertices are split into upper/lower copies so
   the jaw can open; wet group = eyeballs + mouth with vertex colours.
3. **Players**: macro targets (MakeHuman weighting, `lib/targets.mjs`) + detail modifiers → uniform scale to the
   barefoot height → joints from the `game_engine` rig strategies → eyeballs fitted to the morphed helper eyes
   (cornea bulge) → smooth normals.
4. **Shared shells** (`lib/shells.mjs`): jersey (tucked: hem pelvis + 0.03 inside the shorts), shorts, 4 sock
   heights (+2 ankle-brace variants), right sleeve, finger tape, left wristband, 2 headbands, lashes; cut on base.obj
   by marching triangles, decimated with every player's shape as attributes (no poke-through on any body), with
   cover lists, garment boundary loops (neck/armholes/hem, waist/legs, cuffs), perimeter tables and LOD1 indices.
5. **Groom shells per player** on the player's own morphed mesh and face frame (`lib/groom.mjs`): hair inner/outer
   (hairline function with temple corner, temporal line, sideburns, ear gap, nape), beard inner/outer (moustache,
   goatee, links, full beard with cheek and neck lines, zone densities), brows; head-metric / brow-local UVs,
   per-vertex density and edge fade.
6. **Expressions** (`lib/morphs.mjs`): the 9 channels of SPEC-v2 §3.9 per player (modifier deltas, jaw rotation
   about the jaw pivot with the shared jaw field, tongue, procedural blink), sparse i16 deltas.
7. **Masks** (`lib/uvraster.mjs`, `lib/masks.mjs`, `lib/png.mjs`): 3 shared + 2 per-player RGB PNGs from 3D
   fields per texel, dilated, budget-checked.
8. **Header + budgets**: format v2 (`FORMAT.md`), byte-size log with the SPEC-v2 §3.1 budgets (header ≤ 140 KB,
   shared ≤ 800 KB, player ≤ 300 KB, masks per file, total ≤ 3.5 MB). Deterministic: same config + cache →
   byte-identical files.

## Config (`legends.config.json`)

Top level: `name`, `notes`, `output` (`../../assets/legends`), `mpfbRef`, `lods`, `keepMouth`, `players`.
Per player:

- `id`, `label`, `height` (barefoot, m), `meta` (`nameZh`, `nameEn`, `era`, `number`, `stats {heightM, barefootM,
  weightKg, wingspanM, reachM}` — equal to `src/legends.js`, `calibration` targets for `calibrate.mjs`).
- `macro` (`gender`, `ageYears`, `muscle`, `weight`, `height: "auto"`, `proportions`, `race`) and `targets`
  (`"<group>/<modifier>": value`; + uses the incr/up target, − the decr/down one; one-sided modifiers ≥ 0;
  `{l, r}` for sided modifiers).
- `expressions`: `{<channel>: {modifiers: {…}, jaw: {rotDeg, translate}, tongue: {translate}, lids: true}}` for the
  channels that player uses.
- `appearance`: the runtime look of SPEC-v2 §2.6 (passed for reference; the game reads `src/legends.js`), and the
  bake-time grooming geometry of §2.8:
  - `hair {style, color, hairline {aboveCm (forehead height measured up the forehead surface from the glabella),
    frontCurveCm, recCm, temple: round|square, sideburnBottom: mid-ear|beard, sideburnWidthCm, earGapMm,
    napeBelowLobeCm, nape: square|taper}, layers [{offsetMm, family {straight, coil, stipple}, density, fadeMm,
    sidesScale?, insetMm?, fringe?}]}`; Jordan: `layers: []`, `horseshoe {phiMin, top, density}`, `gloss {aboveGyM,
    fadeCm}`.
  - `beard {style, color, components {M {heightMm?, gapMm, dropMm, density, centreScale/centreMm | outerScale/
    outerMm}, Gt {wCm, hCm, soulWCm, density}, Lk {density, widthMm}, F {yA, dA, yB, dB, dN, moustache,
    moustacheGapMm, zones {all | jaw, chin, cheeks}}, J {jaw, bandM | upperLip, chin}}, layers [inner {offsetMm,
    family, fadeMm}, outer {chinMm, cheeksMm, density, insetMm, fadeMm}]}` (landmark heights like `"T.y-0.004"`).
  - `eyebrows {gap, arch, tail, hIn, hOut, density, shape, offsetMm, archOuter?}`, `tattoos [{kind: armBlobs |
    backArch | dottedBracket, …}]`, `kit`, `shoes`, `accessories` (SPEC-v2 §2.7 data).

`notes` lists every deviation from the likeness profiles and the calibration conventions.

## Measure, calibrate, likeness

`measure.mjs <header.json> [--json] [--likeness]` reads only the baked files: height, head height (crown → ME
landmark) and heads tall, crown→eye : eye→chin (`craniumFace`), shoulder/chest/waist/hip breadths, wingspan and
overhead reach by CPU skinning, hand/foot length, leg ratio, mass from the closed volume. `--likeness` adds the
SPEC-v2 §10.2 face metrics (`faceLW`, `chinProj`, `earOut`, `fissH`, `lipsH`, `noseIcd`; definitions and bands in
`lib/landmarks.mjs`) and exits 1 on any band or ordering miss.

`calibrate.mjs <config> [--iters n] [--write]` keeps every likeness modifier and solves the calibration knobs
(`forehead-scale-vert`, `head-scale-vert`, `measure-shoulder-dist`, `hand-scale`, `foot-scale`, both arm lengths,
`macro.weight`) against `meta.calibration`, re-baking with `bake(…, {fast: true})` each iteration (~2 s).
